Для обучения или перекалибровки положите сюда `calo_dictionary*.npz`.
Эти большие исходные файлы в архив не включены; для обычного вывода по готовым
весам они не требуются.

Каждый NPZ должен содержать:

- `keys`: `(K, 3)`, столбцы `[y, E, g]`;
- `values`: `(K, R, 4, 8, 8)`, R повторов для каждого ключа.

Классы y=0 и y=1 должны присутствовать на каждом условии `(E,g)` с одинаковым
числом повторов. E в [1, 100], g в [0.7, 1.3]. Всего не более 1 000 000 событий.
Все значения конечные, энергии неотрицательные, ключи не повторяются между файлами.

Для `--mode recalibrate` и `--mode pretrained --evaluate-data` с вложенными
готовыми весами требуются ВСЕ ТРИ исходных словаря, идентифицируемые по SHA-256.
Их имена из checkpoint:

- `calo_dictionary_300000(3).npz`;
- `calo_dictionary_50000(4).npz`;
- `calo_dictionary_649800(3).npz`.

Имя можно поменять на любое `calo_dictionary*.npz`; содержимое менять нельзя,
так как сохранённые индексы test/train относятся к конкретным исходным файлам.
Для `--mode train` разрешены другие данные в указанном формате; будет создана
новая сеть с новой нормализацией и независимыми частями данных.
