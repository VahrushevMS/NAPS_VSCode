Здесь лежит `session_demo.npz`: 32 искусственных события для проверки запуска.
Они не являются вашими исходными данными и не используются для оценки качества.

Положите сюда свои `session*.npz`, содержащие массив `X` формы `(N, 4, 8, 8)`
и необязательный массив `event_id` длины `N`. Энергии должны быть конечными и
неотрицательными. Также принимается ключ `values`, одно событие `(4, 8, 8)`
или массив `(K, R, 4, 8, 8)`; последняя форма разворачивается в порядке K, затем R.

Запуск создаст для каждого файла `outputs/submission_<имя_файла>.csv`.
Файлы с другими именами можно передавать через `--session путь.npz`.
