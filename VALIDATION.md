Короткий полный прогон использовал 9 216 искусственных событий при 384 условиях,
по 12 событий каждого класса на условие. Он проверял работоспособность модулей,
сохранение и повторное чтение checkpoint, а не качество на ваших физических данных.
Малого числа событий guard недостаточно для нетривиальных порогов: в этой
проверке получается консервативное множество из обоих классов. Это не результат
приложенной обученной модели.

Для Windows проверялся выбор бинарных пакетов и разрешение зависимостей с
Windows-маркерами. Сам Windows, окно VS Code и GPU в этой среде не запускались.
Windows-скрипты подготовлены с CRLF и UTF-8, конфигурации содержат отдельные пути
к Windows- и Linux-интерпретаторам.

Полное обучение или повторный test на исходных 999 800 событиях при упаковке
не выполнялись: исходные NPZ в текущем комплекте не предоставлены.
Веса содержат сохранённые результаты исходного test; стандартный запуск
явно показывает их источник и не представляет их как новую оценку.

Проверки можно воспроизвести:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests/smoke_training.py
```

В Linux замените `.\.venv\Scripts\python.exe` на `./.venv/bin/python`.
Для `smoke_training.py` сначала установите CatBoost через
`python bootstrap.py --install-only --with-training`.
